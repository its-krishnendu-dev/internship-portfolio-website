
# Personal Portfolio Website

A modern, responsive personal portfolio website developed as part of my internship project. Designed to showcase my skills, projects, experience, and contact information with a clean and attractive user interface.

## 🚀 Features

- Modern and responsive UI design
- Dark and light mode toggle
- Responsive navigation with hamburger menu
- Skills section with technology logos
- Project showcase with interactive slider
- Contact form with validation
- Smooth hover effects and transitions
- Mobile, tablet, and desktop compatibility
- Professional footer section

## 🛠️ Technologies Used

- HTML5
- Tailwind CSS
- JavaScript (Vanilla JS)
